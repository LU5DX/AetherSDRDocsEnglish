# Profile Switcher overview

The Profile Switcher is a quick-access tile in the Applet Panel that lets you switch between saved transmit profiles (mic, processor, EQ, filter settings) without opening the full Profile Manager dialog. It shows the active profile name and lets you cycle through or jump to profiles with one click.

## Before you start

- A radio connection must be active.
- You must have at least one saved transmit profile. Create and manage profiles from `Profiles > Profile Manager...`.

## How it works

The Profile Switcher appears as a tile in the Applet Panel labeled "PSW". It displays the name of the currently active transmit profile and provides three ways to switch profiles:

1. **Click Previous or Next arrows** — Cycle to the previous or next transmit profile in the list.
2. **Click the profile menu button** — Opens a dropdown menu to jump directly to any saved profile.
3. **Use the Profiles menu** — From the top menu bar, `Profiles` shows a checkable list of active global profiles below the separator.

When you select a different profile, the radio immediately applies its transmit settings (mic gain, equalization, processor, filter bandwidth, etc.).

## What each control does

| Control | Type | Behavior |
|---------|------|----------|
| Current profile name | Indicator | Shows the name of the currently active transmit profile. |
| Previous / Next profile | Push button | Cycle to the previous or next transmit profile in the list. |
| Profile menu | Push button | Opens a dropdown menu listing all saved profiles; click one to load it. |

## Troubleshooting

- **Profile Switcher tile is not visible** — The applet must be added to the Applet Panel first. Open the Applet Panel and look for the Profile Switcher tile; if missing, right-click the panel area and select "Profile Switcher" to add it.
- **No profiles appear in the menu** — No transmit profiles have been saved. Open `Profiles > Profile Manager...` to create a new profile.
