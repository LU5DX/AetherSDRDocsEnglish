# Cycle through transmit profiles quickly

Switch between saved transmit profiles using the Profile Switcher applet — useful when changing bands, modes, or operating conditions without opening the full Profile Manager dialog.

## Before you start

- Radio must be connected.
- At least one transmit profile must be saved (create one in `Profiles > Profile Manager...`).

## Steps

1. Open the **Applet panel** and locate the **Profile Switcher** tile.
2. Click the **Next profile** button to advance to the next profile in the list, or click the **Previous profile** button to go back.
   - The display updates to show the name of the newly active profile.
3. To jump directly to a specific profile without cycling:
   - Click the **Profile menu** button.
   - Select the desired profile from the dropdown list.

## What each control does

| Control | Behavior |
|---------|----------|
| Current profile name | Shows the name of the currently active transmit profile. |
| Previous / Next profile | Cycles forward or backward through the saved profile list. |
| Profile menu | Opens a dropdown menu to select any saved profile directly. |
