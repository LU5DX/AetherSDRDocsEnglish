# See which profile is currently active

The Profile Switcher applet shows the name of the currently active transmit profile, so you always know which mic, processor, EQ, and filter settings are in use.

## Before you start

- Your radio must be connected.
- At least one transmit profile must exist (saved via **Profiles > Profile Manager...**).

## Steps

1. Open the Applet Panel tray (bottom of the AetherSDR window).
2. Locate the **Profile Switcher** tile (labeled **PSW**).
3. Read the profile name displayed on the tile — this is the currently active transmit profile.

## What each control does

| Control | Behavior |
|---|---|
| Current profile name (indicator) | Shows the name of the active transmit profile. |
| Previous / Next buttons | Cycle to the previous or next transmit profile in the list. |
| Profile menu button | Opens a dropdown menu to jump directly to any saved profile. |
