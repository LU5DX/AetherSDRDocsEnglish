# Activate a memory with a single click

Activate a stored memory on the tuned slice by clicking it in the Memory Browser panel. This lets you quickly jump to a saved frequency without typing or menu navigation.

## Before you start

- Your radio must be connected and powered on.
- At least one memory must be stored on the radio. If no memories exist, the Memory Browser panel shows "No memories are available yet."

## Steps

1. Open the Memory Browser panel. It appears as a side panel in the main window splitter when memory browsing is enabled.
2. Locate the memory you want to activate in the table. Memories are sorted by frequency.
3. Click the row for that memory.

The tuned slice immediately changes to the memory's frequency. The closest memory to the current frequency is highlighted with a distinct background color.

## What each control does

| Control | Behavior | Notes |
|---|---|---|
| Memory table | Shows each memory sorted by frequency; single-click or Enter to activate the tuned slice to that memory | Columns: Frequency, Name. Closest memory to current tuning is highlighted with a distinct background. Double-click also tunes. |
| Highlighted row | Memory closest to current tuning has a distinct background color | Updates automatically as you tune |
| Add Memory | Saves the current slice on this panadapter as a memory | Added at the top of the panel, above the memory list. Inserted at the top of the panel layout in v26.7.4. |
| No memories are available yet. | Shown when the radio has no memories loaded | |

## Tips

- Double-clicking a memory row also activates it.
- Press Enter while a row is highlighted to activate that memory.
- The panel is fixed at 252×460 pixels.
