# Add a memory from the active slice using the panel button

Save the current active slice as a memory entry in the radio’s memory list so you can recall it later.

## Before you start

- A radio must be connected.
- The Memory Browser panel must be visible in the MainWindow side panel.

## Steps

1. Tune the active slice to the frequency and mode you want to save.
2. In the Memory Browser panel, click **Add Memory**.

The slice’s frequency and name are saved as a new memory entry, which appears immediately in the memory table.

## What each control does

| Control | Behavior |
|---------|----------|
| **Add Memory** | Saves the current slice as a new memory entry. Always visible at the bottom of the panel, anchored outside the scrolling table. Tooltip: “Save the current slice on this panadapter as a memory.” |

## Tips

- The memory is stored on the radio itself, not locally — the name and frequency come from the active slice’s current settings.
