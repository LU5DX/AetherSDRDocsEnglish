# Edit or delete a scheduled net

Edit the name, frequency, mode, recurrence rule, or reminder for an existing net, or remove a net from your schedule entirely.

## Before you start

- The Net Scheduler dialog must be open (`Tools > Net Scheduler...`).
- At least one net must already exist in the net table.

## Steps

1. In the net table, click the row of the net you want to edit or delete to select it.
2. Click **Edit / Delete**.
3. To edit, make your changes in the net editor dialog, then confirm.
   To delete, click the delete option in the dialog.

## Each control does

| Control | Behavior |
|---|---|
| Net table | The list of all scheduled nets. Click a row to select it before using Edit, Delete, Tune Now, or Import/Export. |
| Edit / Delete | Opens a dialog for the selected net. You can change the net’s name, frequency, mode, recurrence rule, and reminder. Or you can remove the net from the schedule entirely. |
| Recurrence rule | How often the net repeats. Default: **Weekly**. Options: Once, Daily, Weekly, Biweekly, Monthly. |
| Reminder | Minutes before net start to show a banner on the panadapter. Default: **5 min**. Range: **1–60 min**. |
