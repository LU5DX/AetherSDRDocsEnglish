# Select a mic profile for a specific microphone

The mic state signal keeps the Phone and mic-related panels in sync with the radio whenever microphone selection or active mic profile changes. Use the steps below to assign a profile to a specific microphone.

## Before you start

- Connect to a radio. Mic profile controls are unavailable when the radio is disconnected.

## Steps

1. Open the **Phone** panel.
2. Select the microphone you want to configure from the **Microphone** selector.
3. Choose a profile from the **Mic Profile** selector. The change takes effect immediately and the panel updates to reflect the new state.

## What each control does

| Control | Behavior |
|---|---|
| Microphone | Selects the active microphone input the profile will apply to. |
| Mic Profile | Assigns a saved mic profile to the currently selected microphone. Switching profiles updates microphone level, speech processor settings, and DAX state to match the stored values. |

## Tips

- If the panel does not reflect your changes, verify the radio is still connected. Disconnecting resets all mic state to defaults.
