# Select a mic profile for a specific microphone

The mic profile setting controls which saved microphone configuration the radio applies to a specific connected microphone. Changes are reflected immediately across the Phone and mic-related panels via the mic state signal.

## Before you start

- Connect to a radio. The mic profile controls are unavailable when the radio is disconnected.
- Ensure the microphone you want to configure is selected as the active microphone.

## Steps

1. Open the **Phone** panel.
2. In the microphone section, locate the **Mic Profile** selector for the connected microphone.
3. Click the selector and choose the desired profile from the list.

The panel updates immediately to reflect the active profile.

## What each control does

| Control | Behavior |
|---|---|
| Mic Profile selector | Applies a saved microphone configuration profile to the currently selected microphone. Triggers a mic state change that updates all mic-related panels. |

## Tips

- If the profile list is empty, no mic profiles have been saved for this radio. Create and save a profile first before selecting one.
- Switching microphones resets the mic state to defaults. Reselect the desired profile after changing the active microphone.
