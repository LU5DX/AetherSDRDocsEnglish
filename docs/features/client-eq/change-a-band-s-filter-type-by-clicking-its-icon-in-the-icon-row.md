# Aetherial Parametric EQ (TX / RX) — Reference Curve Overlay & Controls

The Aetherial Parametric EQ provides a client-side equalizer with two independent copies: "Aetherial TX EQ" and "Aetherial RX EQ". Each docked tile (minimum 110 px tall) shows the summed EQ response with a live FFT analyzer overlay, peak-hold trace, and dashed yellow guide lines at the radio's current filter cutoff edges. All editing happens in the frameless floating editor window titled "Aetherial Parametric EQ — TX" or "Aetherial Parametric EQ — RX".

## Reference curve overlay

The reference curve overlay lets you display a target frequency-response curve on the EQ canvas as a visual guide while shaping your parametric EQ bands. This is useful for matching the tonal characteristics of classic microphones or voice-processing targets.

### Before you start

- The floating editor must be open. The reference curve selector is only available in the "Aetherial Parametric EQ — TX" or "Aetherial Parametric EQ — RX" frameless editor window, not in the docked applet tile.
- If the editor is not open, double-click the EQ stage in the CHAIN widget on the TX or RX side to open it. See [Open the frameless editor to add / remove / tune bands on either side](open-the-frameless-editor-to-add-remove-tune-bands-on-either-side.md).

### Steps

1. Open the floating editor for the TX or RX side as needed.
2. Locate the **Reference curve** combo box at the bottom of the editor header strip, just above the canvas.
3. Click the combo box and select one of the available presets:
   - **Off** — no reference curve displayed
   - **AT&T 1959** — Bell Labs optimum transmission frequency response for speech; peak +5 dB at 2.5 kHz
   - **Heil DX** — Bob Heil's contest/pile-up recommendation; sharper +6 dB peak at 2.7 kHz
   - **Astatic D-104** — classic "lollipop" crystal mic response; peaky presence around 3 kHz
   - **Shure 444** — classic broadcast desk mic; broader response with gentler presence boost
   - **Heil HC-5** — modern dynamic SSB mic; mid-presence boost peaks ~3 kHz at +5 dB
4. The selected reference curve appears as an amber, semi-transparent line overlaid on the EQ canvas. The curve is drawn after the analyzer but before the EQ band curves, so your adjustments sit on top of the target shape.
5. Adjust your parametric EQ bands to match the reference curve as desired.
6. To remove the reference curve, select **Off** from the combo box.

## Tips

- The hint text in the editor header strip reads "click icon to cycle type" — this is the only action the icon row supports; there is no right-click menu on individual icons.
- If an icon appears dimmed (35% opacity), that band is bypassed. Its filter type can still be cycled, but the band will have no effect on the EQ curve until it is re-enabled.
- The filter family selected in the Filter family combo (default: Butterworth) governs HP and LP cascade mathematics. Changing a band to an HP or LP type will use the currently selected family. Peak and shelf bands use their own fixed 2nd-order topology regardless of the Filter family setting.
- To edit a band's numeric values directly, right-click a column in the parameter text row and enter the desired Freq, Gain, or Q value. Press Enter to commit — the value is clamped to the valid range, settings are saved immediately, and the canvas and icon row update to reflect the change.
- The reference curve is for visual reference only — it does not affect the actual EQ math or audio processing. Use it as a target while shaping your parametric EQ bands.
- The reference curve selection is shared between the TX and RX editors — changing it in one editor also updates the other. The selection is persisted as a single user preference (`ClientEqReferenceCurve`).
- The analyzer display smoothing (Smoothing combo) affects only the visual trace — the EQ math and the peak-hold trace remain on raw frequency bins so transient peaks are not masked.

## Troubleshooting

- **The icon row is not visible** — The icon row is only present in the floating editor, not in the docked "Aetherial TX EQ" or "Aetherial RX EQ" applet tile. Open the floating editor by double-clicking the EQ stage in the CHAIN widget.
- **Clicking an icon has no effect on the EQ curve** — The band may be bypassed (icon is dimmed to 35% opacity). Re-enable the band to hear the filter type change reflected in the summed curve.
- **The parameter text row appears to overlap the band-plan strip** — This was a display issue in versions prior to v0.9.7 where the row's dark background bled upward over the band-plan strip at the bottom of the canvas. Update to v0.9.7 or later to resolve it.
- **The reference curve is not visible** — Ensure you have selected a preset other than "Off" from the Reference curve combo box. The curve is amber and semi-transparent; it may be difficult to see against a busy analyzer display.
