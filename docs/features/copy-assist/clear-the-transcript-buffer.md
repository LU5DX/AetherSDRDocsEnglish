# Clear the transcript buffer

This page explains how to clear the accumulated speech-to-text transcript in the Copy Assist panel, typically done between contacts or to start fresh.

## Before you start

- The Copy Assist panel must be open (View > Copy Assist, or press Ctrl+Shift+T).
- Transcription does not need to be active to clear the buffer.

## Steps

1. Open the **Copy Assist** panel: **View > Copy Assist** (Ctrl+Shift+T).
2. Find the **Clear** button at the bottom of the Copy Assist panel.
3. Click **Clear**. The transcript text field empties immediately.

## Tips

- Clearing does not stop transcription — the engine continues listening and will begin filling the buffer from where it left off.
- The clearance is instant; no confirmation dialog appears.

## Troubleshooting

- **Clear button does not respond** — If the Copy Assist panel is not visible, ensure you have the panel open via **View > Copy Assist**. If the button still doesn't respond, try closing and reopening the panel.
