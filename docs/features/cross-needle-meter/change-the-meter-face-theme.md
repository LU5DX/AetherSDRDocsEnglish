# Change the meter face theme

Choose a different visual style for the cross-needle meter's face, such as classic black, white, military, or other presets.

## Before you start

- A radio must be connected (the cross-needle meter requires a live radio connection).
- The Cross-Needle Meter applet must be open in the Applet Panel.

## Steps

1. Open the Cross-Needle Meter applet: **Applet panel > Cross-Needle tile**.
2. Locate the **Meter face theme** combo box.
3. Click the combo box and select your desired theme from the list.

The meter face updates immediately to show the chosen style.

## What each control does

| Control | Type | Behavior |
|---------|------|----------|
| Meter face theme | Combo box | Selects the visual style of the meter face. Options include classic black, white, military, and other presets. |

## Tips

- The theme affects only the meter face background and scale markings; it does not change needle behavior or readout values.
- To see theme options clearly, make sure the applet is large enough to show the full meter face.
