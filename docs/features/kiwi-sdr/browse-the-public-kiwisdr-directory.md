# Browse the public KiwiSDR directory

Open the KiwiSDR applet to search and browse the public directory of KiwiSDR receivers available worldwide, with details on each receiver's name, location, band, and status.

## Before you start

- AetherSDR must be running (no radio connection required)

## Steps

1. Open the Applet panel (if not already visible).
2. Click the **KiwiSDR** tile to open the applet.
3. In the **Receiver list**, type a search term (e.g., a location or band) to filter the directory.
4. Browse the list of available receivers showing their name, location, band, and connection status.

## What each control does

| Control | Description |
|---------|-------------|
| **Receiver list** | Searchable, scrollable list of public KiwiSDR receivers with name, location, band, and status. |
| **Assign to slice** | Assigns the selected KiwiSDR receiver to the active slice for tuning and listening. |
| **Status indicator** | Shows connection state (Disconnected / Connecting / Connected / Error) with detail text. Default: Disconnected. |

## Tips

- The directory refreshes when you open the applet, showing currently online receivers.
- Use the search field to quickly find receivers in a specific region or band.
