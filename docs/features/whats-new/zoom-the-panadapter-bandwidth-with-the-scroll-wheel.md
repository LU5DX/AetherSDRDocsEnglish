# Zoom the panadapter bandwidth with the scroll wheel

The Spectrum / Waterfall widget renders the live FFT spectrum and scrolling waterfall for one panadapter. You can scroll the mouse wheel directly over the spectrum to zoom the displayed bandwidth in or out.

## Steps

1. Open the Panadapter applet. The Spectrum / Waterfall widget is always visible inside it.
2. Position your mouse cursor over the spectrum or waterfall area.
3. Scroll the mouse wheel up to zoom in (narrow the displayed bandwidth) or down to zoom out (widen the displayed bandwidth).

## What each control does

| Control | Behavior |
|---|---|
| Waterfall colour scheme | Changes the gradient palette used to map signal intensity to waterfall colour. Persisted per-panadapter. |

## Tips

- Zooming centres on the current tuned frequency. Tune to a signal of interest before zooming in for a closer view.
- If you want to change how the waterfall looks while zoomed, use the **Waterfall colour scheme** selector inside the same panadapter to switch between Default, Grayscale, Blue-Green, Fire, and Plasma palettes.
