# Search within the release notes using the Find button

Search for text within the live GitHub release notes displayed in the What's New dialog. This is useful when you want to find a specific feature, bug fix, or change mentioned in a long set of release notes.

## Before you start

- The What's New dialog must be open. If it isn't, open it from `Help > What's New...`

## Steps

1. In the What's New dialog, click **Find** in the bottom toolbar.
2. In the input dialog that appears, type the text you want to search for.
3. Press **Enter** or click **OK**.
4. The release notes browser highlights the first match. Continue clicking Find or pressing Enter to cycle through all matches (wrapping around to the start when reaching the end).
5. Click **Close** in the Find input dialog to dismiss the search.

## Tips

- The search wraps around — after reaching the last match, it continues from the first match again.
- To dismiss the search without closing the What's New dialog, simply close the Find input dialog.
