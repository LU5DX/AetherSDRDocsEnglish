# Mute the speaker or headphones

The Title Bar provides separate mute toggles for the line-out speaker and headphones, letting you silence either output instantly without changing the volume level.

## Steps

1. To mute the speaker, click the **🔊 (line out mute)** button in the Title Bar. The icon changes to 🔇 to confirm mute is active. Click it again to unmute.
2. To mute the headphones, click the **🎧 (headphone mute)** button in the Title Bar. The icon changes to 🔇 to confirm mute is active. Click it again to unmute.

## What each control does

| Control | Behavior |
|---|---|
| **🔊 (line out mute)** | Toggles line-out speaker audio on and off. Icon changes to 🔇 when muted. |
| **Master volume** | Sets the line-out audio level (0–100, default 100). The current value appears in a numeric label to the right of the slider. |
| **🎧 (headphone mute)** | Toggles headphone audio on and off. Icon changes to 🔇 when muted. |
| **Headphone volume** | Sets the headphone audio level (0–100, default 50). The current value appears in a numeric label to the right of the slider. |

## Tips

- Muting does not change the slider position. When you unmute, audio resumes at the same volume level that was set before muting.
- To reduce volume instead of muting completely, drag the **Master volume** or **Headphone volume** slider rather than using the mute toggle.
