# Adjust headphone volume

The Title Bar provides dedicated headphone volume controls, separate from the main line-out speaker, so you can set a comfortable listening level for connected headphones without affecting other audio outputs.

## Steps

1. Locate the **🎧 (headphone mute)** toggle button in the Title Bar. If the icon shows 🔇, click it to unmute headphone audio.
2. Drag the **Headphone volume** slider left or right to set the desired level (0–100). The current value appears in the numeric label to the right of the slider. The default level is **50**.

## What each control does

| Control | Behavior |
|---|---|
| **🎧 (headphone mute)** | Click to mute or unmute headphone audio. Icon changes to 🔇 when muted. |
| **Headphone volume** | Sets the headphone audio level (0–100). The current value is shown in a numeric label to the right. Default is 50. |

## Tips

- The **Headphone volume** slider is independent of the **Master volume** slider, which controls line-out audio only. Adjust each separately to match your listening setup.
- If you hear no audio after adjusting the slider, check that the **🎧 (headphone mute)** icon is not showing 🔇.
