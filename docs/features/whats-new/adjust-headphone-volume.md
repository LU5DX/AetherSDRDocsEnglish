# Adjust headphone volume

The Title Bar provides a dedicated headphone volume slider and mute toggle so you can set your headphone listening level independently of the main speaker output.

## Steps

1. Locate the **🎧 (headphone mute)** toggle button in the Title Bar. If the icon shows 🔇, click it once to unmute headphone audio.
2. Drag the **Headphone volume** slider left or right to set the desired level (0–100). The numeric label to the right of the slider updates as you drag. The default level is 50.

## What each control does

| Control | Behavior |
|---|---|
| **🎧 (headphone mute)** | Click to mute or unmute headphone audio. Icon changes to 🔇 when muted. |
| **Headphone volume** | Drag to set the headphone audio level from 0 to 100. Current value is shown in the numeric label to the right. Default is 50. |

## Tips

- The **Headphone volume** setting is not persisted across sessions; it resets to 50 on next launch. Set it each time you open AetherSDR if you prefer a level other than the default.
- To adjust the main speaker output instead, use the **Master volume** slider (default 100) and its associated **🔊 (line out mute)** toggle, both located to the left of the headphone controls in the Title Bar.
