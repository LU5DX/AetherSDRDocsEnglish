# Add a memory at current frequency

Open the Memory Channels dialog and save the active VFO frequency as a new memory channel entry. Use this to bookmark a frequency you want to return to later.

## Before you start

- Connect to a FLEX-8600 radio. The Memory Channels dialog requires an active radio connection.
- Tune the active slice to the frequency you want to store.

## Steps

1. Click `Settings > Memory...` to open the Memory Channels dialog.
2. Click `Add`.

A new row appears in the memory table populated with the current VFO frequency. The memory is saved immediately to the radio.

3. To give the memory a name or adjust other fields, select the new row and click `Edit`, then modify the fields inline. See [Edit a memory's name, mode or offset inline](edit-a-memory-s-name-mode-or-offset-inline.md).

## Tips

- Double-clicking a row in the memory table tunes the active slice to that memory directly.
- To find the memory you just added, use the `Search:` field to filter by name, or sort the Frequency column by clicking the column header.
- The search and profile filters work together — selecting a profile filters the table, and typing in the search field further narrows the results.
