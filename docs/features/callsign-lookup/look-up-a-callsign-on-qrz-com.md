# Look up a callsign on QRZ.com

Query an amateur radio callsign on QRZ.com and other online databases to see the operator's name, location, grid square, DXCC entity, country flag, license class, and biography.

## Before you start

- **No radio connection required** — the dialog works offline from the internet.
- For full name, address, and biographical data, a **QRZ.com XML subscription** is recommended. Without it, results may be limited to basic callsign information.

## Steps

1. Go to **Tools > Callsign Lookup...** in the main menu.
2. In the Callsign field, type the callsign you want to look up.
3. Press **Enter** or click the **Lookup button**.
4. The callsign card displays the result: operator name, location, grid square, DXCC entity, country flag, license class, and biography (when available).

## Tips

- You can also right-click a spot in the panadapter and choose **Lookup** to automatically fill the callsign field from that spot.
- The grid square shown in results can be used to calculate distance and bearing from your station.
