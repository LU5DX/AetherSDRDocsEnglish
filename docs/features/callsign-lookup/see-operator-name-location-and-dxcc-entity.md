# See operator name, location and DXCC entity

Look up a callsign and view the operator's name, location, grid square, DXCC entity, country flag, license class, and biography — all displayed in a single callsign card.

## Before you start

- You need an active internet connection to query online databases.
- For full data (name, address, DXCC entity), a valid QRZ.com XML subscription is required.

## Steps

1. Open the Callsign Lookup dialog via **Tools > Callsign Lookup...**
2. Type the callsign you want to look up into the **Callsign field**.
3. Press **Enter** or click **Lookup** to perform the query.
4. Read the results in the **callsign card**, which shows:
   - Operator name
   - Location (city, state/province, country)
   - Grid square
   - DXCC entity
   - Country flag
   - License class
   - Biography (if available)

## What each control does

| Control | Description |
|---|---|
| **Callsign field** | Text field for entering a callsign. Press Enter or click Lookup to start the query. |
| **Lookup button** | Sends the query to QRZ.com and other configured databases. Requires QRZ.com XML subscription for full data. |
| **Callsign card** | Displays the complete lookup result — name, location, grid square, DXCC entity, country flag, license class, and biography. |
