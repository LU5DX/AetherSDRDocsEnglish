# View the callsign card with flag and details

Look up an amateur radio callsign on QRZ.com to see the operator's name, location, grid square, DXCC entity, country flag, license class, and biography in a single card display.

## Before you start

- A QRZ.com XML subscription is required for full data including the card display with flag, map, and bio
- Radio connection is **not** required — lookup works offline from the radio

## Steps

1. Open **Tools > Callsign Lookup...**
2. Type the callsign into the **Callsign field**
3. Press Enter or click **Lookup** to query QRZ.com and other configured databases
4. The **Callsign card** appears showing the result — see operator name, location, DXCC entity, country flag, grid square, license class, and bio

## What each control does

| Control | Type | Behavior |
|---------|------|----------|
| **Callsign field** | text field | Enter a callsign. Press Enter or click Lookup to start the query. |
| **Lookup button** | push button | Queries QRZ.com and other configured databases for the entered callsign. Requires QRZ.com XML subscription for full data. |
| **Callsign card** | indicator | Displays the lookup result: operator name, location, grid square, DXCC entity, country flag, license class, and biography. |
