# Enable FPS Meters

Toggle FPS meters to display spectrum and waterfall frame rate readouts in the footer. This helps you monitor performance and diagnose rendering issues.

## Before you start

- AetherSDR must be running and connected to a radio.

## Steps

1. Open the **View** menu.
2. Click **FPS Meters** to check it (enable) or uncheck it (disable).

## What each control does

| Control | Description | Default | AppSettings key |
|---|---|---|---|
| **FPS Meters** (View menu) | Toggles spectrum/waterfall FPS readouts in the footer. | Off (unchecked) | `DisplayFpsMeters` |

## Tips

- Use FPS meters to verify that UI scale or other visual settings aren't causing framerate drops.
- The readout appears in the main window footer, between other status indicators.
