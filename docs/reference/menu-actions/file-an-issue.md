# File an Issue

Use this page to report a bug in AetherSDR directly to the developers. The File an Issue command opens your default browser at the AetherSDR issue tracker so you can describe the problem you encountered.

## Before you start

- A working internet connection.
- A GitHub account is required to submit an issue.

## Steps

1. Open the **Help** menu.
2. Select **File an Issue...**.

Your default web browser opens the AetherSDR issue tracker. Fill in the issue template with as much detail as possible — what you were doing, what you expected to happen, and what you saw instead.

## Tips

- The File an Issue command was added in v26.8.4. In earlier builds, bug reporting was only available through the Support dialog.
- Before submitting, check the issue tracker for an existing report about the same problem. Comment on it rather than opening a duplicate.
