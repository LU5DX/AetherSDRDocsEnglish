# Configure Workspace Canvas

Turn the workspace canvas shell on or off to move pans and applets into freely placed windows, and recall named layouts with the Workspaces switcher. The canvas is off by default and optional.

## Before you start

- AetherSDR v26.8.4 or later (multi-window workspace canvas, phase 7).

## Steps

1. Open **View > Workspace Canvas**.
2. Click **Enabled** to turn the workspace canvas on. AetherSDR migrates the current layout into a workspace named "Classic".
3. (Optional) Click **Edit Layout** to arm placement of pans and applets.
4. (Optional) Use the **Workspaces** switcher to recall named layouts.
5. (Optional) Open the **Canvas Windows** submenu to list additional workspace canvas windows.
6. To return to the normal shell, open **View > Workspace Canvas** and click **Enabled** again to clear the checkbox.

## What each control does

| Control | Behavior |
|---|---|
| **Enabled** | Checkable. Turns the workspace-canvas shell on or off (off by default). Enabling migrates the current layout into a "Classic" workspace; disabling restores the normal shell. |
| **Edit Layout** | Checkable. Arms placement of pans and applets. |
| **Workspaces** | Switcher that recalls named layouts. |
| **Canvas Windows** | Submenu that lists additional workspace canvas windows. |

## Tips

- Enable **Edit Layout** before trying to move pans or applets; without it, placement is not armed.
