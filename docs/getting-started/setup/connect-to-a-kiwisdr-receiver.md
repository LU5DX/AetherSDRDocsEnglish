# Connect to a KiwiSDR receiver

Browse the public KiwiSDR directory and connect to a remote receiver for listening through AetherSDR. This lets you tune and listen to KiwiSDR receivers worldwide without needing a physical radio connection.

## Before you start

- AetherSDR must be running (a radio connection is not required — the KiwiSDR applet works independently)
- The KiwiSDR applet relies on internet access to discover public receivers

## Steps

1. Open the Applet Panel and click the **KiwiSDR** tile.
2. The KiwiSDR applet displays a searchable list of public receivers. Scroll or use the search field to find a receiver.
3. Click a receiver in the list to select it.
4. Click **Assign to slice**. The selected KiwiSDR is assigned to the active slice, and the status indicator shows the connection state.

## What each control does

| Control | Description |
|---------|-------------|
| Receiver list | Searchable, scrollable list of public KiwiSDR receivers showing name, location, band, and status |
| Assign to slice | Assigns the selected KiwiSDR receiver to the active slice for tuning and listening |
| Status indicator | Shows connection state: Disconnected (default), Connecting, Connected, or Error |
